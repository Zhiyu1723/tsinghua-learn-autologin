# 正常情况下：第一次运行程序会弹窗让你输入账号密码，然后加密保存在本机
# （credentials.dat，用 Windows 的 DPAPI 加密，只有这台电脑的这个用户能解开），
# 以后运行直接读取，不会再弹窗。
#
# 只有在你想用明文文件时（加参数 --creds 指向它）才需要照着下面写。
# 注意：程序读到明文文件后，会自动把账号加密保存成 credentials.dat，
# 并在确认能解回来之后删掉这个明文文件。
#
# 写法要求：
#   - 等号两边不要加空格，也不要用引号包起来
#   - 以 # 开头的行是注释，可以整行删掉
#   - 账号是学号/工作证号/账号，也就是网络学堂登录时填的那个
#   - 明文密码不要放在共享目录或网盘同步目录里；
#     如果发现别的账号也能读到它，可以这样收紧权限（只留自己和系统）：
#       icacls credentials.txt /inheritance:r /grant:r "%USERNAME%:(F)" "NT AUTHORITY\SYSTEM:(F)" "BUILTIN\Administrators:(F)"
