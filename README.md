# 清华大学网络学堂 自动登录（Windows）

双击一下，自动打开网络学堂并登录，停在课程页。

## 怎么用

0. 从release下载最新的压缩包然后解压到任意目录。
1. 需要 [Node.js](https://nodejs.org/zh-cn/download) 22 或更新版本（启动器会自己检查，没装会带你装）。
2. 双击 `autorun.vbs`。
3. **第一次运行**会开一个终端窗口，让你输入网络学堂的账号和密码（密码显示为 `*`）。输入一次之后，账号密码加密保存在本机，以后运行直接读取，不再询问。
4. 登录成功后浏览器保持打开，可以直接用。

想给程序加参数，用记事本打开 `autorun.vbs`，改 `EXTRA_ARGS` 那一行（里面的引号要写成两个）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `autorun.vbs` | 双击这个启动。检查 Node.js → 需要时让你输账号 → 调主程序 |
| `tsinghua-learn-autologin.mjs` | 主程序：开独立 Edge 窗口、自动跳转统一身份认证、填账号密码 |
| `credential-store.ps1` | 用 Windows DPAPI 加解密账号密码（`-Save` / `-Load`） |
| `credentials.example.txt` | 明文账号文件的格式说明（一般用不到，只有 `--creds` 才需要） |

## 常用参数

```
node tsinghua-learn-autologin.mjs --help
```

- `--trust-browser`：勾选认证页的「信任浏览器（统一登录）」，一段时间内免密
- `--copy-profile`：首次运行时把你平时 Edge 的书签、图标复制到独立窗口
- `--creds <文件>`：改用明文账号文件（程序读到后会加密保存并删掉明文）
- `--dry-run`：只打开页面并填好账号密码，不提交

## 注意

- 账号密码只保存在**本机**：`credentials.dat` 用 DPAPI 加密，密钥由 Windows 按「这台电脑 + 这个用户」保管，文件拷到别的电脑或别的用户下都解不开。**不要把这个文件提交到仓库或发到网上。**
- 登录被认证系统拒绝时，程序会删掉保存的账号，下次运行重新询问。想主动换账号，删掉 `credentials.dat` 再运行即可。
- 站点改版后可能需要调整选择器，程序对失败情况会给出中文提示和现场截图（在系统临时目录里）。
